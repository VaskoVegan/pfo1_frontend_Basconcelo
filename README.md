# PFO1 - Portfolio Personal | Rubén Basconcelo

Landing de portfolio personal desarrollada para la PFO1 de la asignatura
Desarrollo de Sistemas Web - Front End.

El proyecto fue realizado utilizando HTML5 y CSS3, con el objetivo de
presentar mi perfil personal, formación, habilidades, trayectoria musical,
proyectos e intereses, además de ofrecer diferentes medios de contacto.

##  Decisiones de diseño

Se eligió una estética oscura con tonos azulados para generar una
apariencia moderna y relacionada con el ámbito tecnológico.

Se utilizó una jerarquía visual clara para diferenciar títulos, textos,
tarjetas y elementos interactivos.

La información fue organizada en diferentes secciones para facilitar la
navegación y evitar una presentación excesivamente extensa.

Las tarjetas se utilizaron para agrupar información relacionada, como
habilidades, proyectos e intereses.

También se incorporaron efectos de transición en elementos interactivos
para mejorar la experiencia de navegación sin sobrecargar visualmente
la página.

---

##  Maquetación

El proyecto utiliza tanto Flexbox como CSS Grid.

### Flexbox

Flexbox se utiliza principalmente para organizar elementos en una misma
dirección, como la navegación, bloques de contenido, información del
inicio y elementos del footer.

### CSS Grid

Grid se utiliza para organizar las tarjetas de habilidades, proyectos e
intereses.

La combinación de ambas tecnologías permite utilizar cada sistema según
la necesidad del componente: Flexbox para estructuras lineales y CSS Grid
para distribuciones bidimensionales. Esta decisión facilita además la
adaptación del contenido a diferentes tamaños de pantalla.

---

##  Diseño responsive

La landing fue desarrollada considerando diferentes tamaños de pantalla.

Se utilizaron media queries para adaptar:

- navegación
- presentación inicial
- imagen de perfil
- tarjetas
- proyectos musicales
- sección de intereses
- formulario
- footer

De esta manera, el contenido puede visualizarse correctamente tanto en
computadoras como en dispositivos móviles.

##  Accesibilidad

Se incorporaron diferentes decisiones orientadas a mejorar la
accesibilidad:

- Uso de etiquetas HTML semánticas.
- Texto alternativo descriptivo en las imágenes mediante `alt`.
- Uso de `label` asociados a los campos del formulario.
- Navegación identificada mediante `aria-label`.
- Contraste suficiente entre texto y fondo.
- Estructura de contenido organizada mediante encabezados y secciones.

##  Uso de Inteligencia Artificial

Durante el desarrollo de esta PFO1 se utilizó ChatGPT como herramienta de
asistencia durante el proceso de aprendizaje y desarrollo.

También utilicé ChatGPT como herramienta de asistencia durante el desarrollo
de mi proyecto personal "Ecos del Horizonte". La herramienta fue utilizada
para analizar ideas, explorar alternativas, detectar posibles problemas y
ayudar a organizar diferentes aspectos del proyecto.

Las ideas originales de jugabilidad, mecánicas, diseño de las losetas,
estructura del juego y concepto general pertenecen a mi propio proceso
creativo. Las respuestas de IA fueron utilizadas como apoyo para analizar y
refinar propuestas, manteniendo las decisiones de diseño bajo mi criterio.

### Herramienta utilizada

- ChatGPT - OpenAI

### Plan utilizado

### Experiencia previa

Ya tenía experiencia previa utilizando ChatGPT como herramienta de apoyo
para estudiar y resolver diferentes actividades relacionadas con el
desarrollo de software.

En este proyecto se utilizó como asistente y no como reemplazo de la

ChatGPT fue utilizado principalmente para:

- Proponer estructuras HTML y CSS.
- Explicar conceptos de HTML, CSS, Flexbox y Grid.
- Ayudar a identificar errores de código.
- Revisar aspectos de diseño responsive.
- Sugerir mejoras de accesibilidad.
- Revisar la estructura del proyecto.
- Ayudar a organizar y documentar el README.
- Analizar la landing en diferentes etapas del desarrollo.

### Trabajo y decisiones propias

Las propuestas generadas mediante IA fueron revisadas y adaptadas durante
el desarrollo.

Las decisiones relacionadas con el contenido personal, trayectoria
musical, formación, intereses, estructura final de la página, selección de
información, imágenes y estética visual fueron tomadas de acuerdo con mi
propio criterio.

También se realizaron modificaciones manuales sobre el código para
adaptarlo a las necesidades concretas del proyecto y comprobar su
funcionamiento en el navegador.

La utilización de IA formó parte del proceso de aprendizaje y revisión,
manteniendo la comprensión y control sobre el código utilizado.
